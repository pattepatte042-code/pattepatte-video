# Patte a Patte - fabrique de videos

Ce depot fabrique automatiquement les Reels de la page Patte a Patte (contenu educatif chiens et chats, Canada).
n8n lance le workflow `render.yml` avec l adresse d une carte ; ffmpeg cree une video 1080x1920 publiee dans la release `videos`.
Aucun secret n est stocke ici.

La musique des Reels est composee automatiquement par music.py (originale, sans droits d auteur tiers).
